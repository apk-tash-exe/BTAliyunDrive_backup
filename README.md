## 📦 What is BTAliyunDrive_backup?

BTAliyunDrive_backup is a backup tool designed to help you save your important files from Aliyun Drive using the 宝塔 panel. It focuses on backing up only new or changed files since the last backup. You can filter files and folders, manage where backups go, and keep your storage tidy automatically.

This tool aims to make backing up data efficient and safe without needing technical skills.

---

## ⚙️ Key Features

- **Incremental Backup**  
  The tool copies only files that are new or changed since your last backup. This saves space and reduces backup time.

- **Backup Versions Control**  
  Choose how many recent backups to keep. The tool deletes older backups, so your storage doesn’t get full.

- **File Name Filters**  
  Include or exclude files by name. You decide what types of files get backed up.

- **Folder Filters**  
  Include or exclude entire folders. This helps focus on important parts of your data.

- **Organized Backup Folders**  
  Backups are automatically sorted by website or database name. This makes finding files easier.
